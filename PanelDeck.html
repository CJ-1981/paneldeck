Help and tips

  • Add a panel: click "Add panel", fill in a name, a link or folder path, and optionally a picture, size, style and accent color.
  • Open a panel: click anywhere on the card. Website URLs open in a new tab; local folder paths open in your system file browser.
  • Local folders: work when this HTML file is opened directly from your computer (double-click it). Browsers block local paths on hosted web pages.
  • Rearrange: drag cards to reorder them (mouse or trackpad). The layout button on a card cycles its size; the pencil button opens the editor where you can change style, picture and color.
  • Renaming: click the dashboard title at the top left to rename it.
  • Backups: everything is stored automatically in this browser (localStorage). Use Export / Import to save or move your dashboard to another computer.
  • Styles: eight card layouts — image top, image side, overlay, compact, tile, glass, banner and note. Mix them with the four sizes freely; the grid adapts.
  • Run file mode: set the click action to "Run file" to launch executables and shortcuts (.exe, .lnk, .bat...) with your operating system. Windows needs a one-time helper — see below. Documents and folders do not need it.
Run file mode — optional Windows helper (one-time setup)

Browsers are not allowed to execute local files directly, so PanelDeck uses a tiny helper: (1) download run.vbs and save it into C:\Users\Public\PanelDeck (create the folder if needed), (2) download the registration file below and double-click it, (3) restart your browser. After that, clicking a "Run file" panel launches the file with Windows.

Only point "Run file" panels at files you trust — they launch with your user permissions. Tip: .lnk shortcuts work too. On macOS / Linux, keep "Open link" for documents; launching executables there requires a custom URL-scheme handler.
